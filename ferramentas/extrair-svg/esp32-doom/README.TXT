ESP32-DOOM in CircuitSketch
===========================

This card does not have the game yet: DOOM1.WAD is missing.

1. Stop the simulation, double-click this card and use
   "Load from the computer" to choose your DOOM1.WAD. The
   shareware one works; the full DOOM.WAD and DOOM2.WAD too.
2. Run it again (F5).

The WAD stays on your computer: the project only keeps its path.
It does not come with CircuitSketch because it belongs to id Software.

Controls (the circuit's buttons, the keyboard or a game controller)
  arrows ....... walk and turn
  Ctrl (A) ..... fire; in the menus, choose
  Space (B) .... use: open doors, press switches
  Esc .......... menu
  switch (R) ... run

The screen also shows up in the browser: the Network panel shows the address.
