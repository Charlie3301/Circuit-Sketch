BASE ZERO - how to make a level

Each level is a /E1Mn.TXT file on this card. The first line is the
level's name; the 16 below are the map, with 16 letters each:

  #  concrete wall     B  brick     M  metal
  D  door (the B button opens it)
  X  exit: the green panel that B presses
  .  floor
  P  where you start
  R  robot      H  health kit      A  ammo

The edge of the map has to be wall (the game closes whatever is left open).
Create /E1M3.TXT and it becomes level 3. The high score stays in /HISCORE.TXT.
